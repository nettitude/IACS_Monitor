# IEC 62443 check reference

Every check IACS_Monitor raises, with its code (`check_name`), where its data comes from, and its cross-reference to the OT Firewall Review 62443 workbook row and to the IEC 62443 requirement.

- **SR**: IEC 62443-3-3 system requirement. **ZCR**: IEC 62443-3-2. **SPE / NET**: IEC 62443-2-1.
- **Workbook row**: checklist id in the OT Firewall Review 62443 workbook (section.item).
- Source of truth: `CHECK_TYPE_REFERENCE` (app/models.py) plus `SUPPLEMENTAL_CHECKS` (generate_report.py); `check_catalogue()` merges them.
- Management and industrial-write checks honour the declared management and engineering networks (docs/management-networks.md).
- 185 checks in `CHECK_TYPE_REFERENCE` plus one catalogued supplemental row (`cross_fw_same_permit_both_sides`, not raised by any check) = 186 rows below. The spreadsheet version (IACS_Monitor_62443_check_reference.xlsx) adds per-source and per-section counts.
